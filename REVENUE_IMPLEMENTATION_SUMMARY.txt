                                ROOT CAUSE ANALYSIS
================================================================================

BEFORE (Broken):
├─ Guest orders created by staff were not tracked in Payment collection
├─ Payment.revenueType was only set to "reception" or "delivery"
├─ No distinction between customer orders vs. staff-created orders
├─ Monthly chart only showed 2 revenue streams
└─ No staff performance tracking for guest orders

AFTER (Fixed):
├─ Guest orders now create Payment records with revenueType="guest_order"
├─ Staff member captured in Payment.createdByStaff field
├─ Revenue dashboard shows 4 revenue types: delivery, reception, guest_order, walkin
├─ Monthly chart displays all 3 main revenue streams with colors
└─ Staff rankings show by guest order revenue generation

================================================================================
                         KEY IMPLEMENTATION DETAILS
================================================================================

1. REVENUE TYPE DETERMINATION (routes/user.js)
   ┌─ Order is "dine-in"?
   │  └─ YES: Order.orderFor === "reception_behalf"?
   │       └─ YES: revenueType = "guest_order"
   │       └─ NO:  revenueType = "reception"
   │  └─ NO: revenueType = "delivery"

2. STAFF ATTRIBUTION (routes/user.js)
   ├─ Guest orders have Order.createdByStaff = reception staff ID
   ├─ Payments capture this: Payment.createdByStaff = Order.createdByStaff
   └─ Revenue controller groups by createdByStaff for breakdown

3. MONTHLY CALCULATION (revenueController.js)
   ├─ Filter payments by revenueType and date range
   ├─ Extract month from payment.createdAt
   ├─ Accumulate revenue into monthlyGuestOrder[month]
   └─ Pass to view for charting

4. DISPLAY LOGIC (views/admin/revenue/index.ejs)
   ├─ Show guest order card with total and breakdown
   ├─ Render staff table with: name, email, count, revenue, percentage
   ├─ Visual progress bars: width = (staff.total / guestOrderTotal) * 100
   └─ Monthly chart: stacked bars with purple = guest orders
